# Security Policy

## Scope

`awesome-compliance-as-code` is a curated catalog of Compliance-as-Code tools, specifications, and reference policy snippets, accompanied by validation scripts and GitHub Actions workflows.

Security issues relevant to this repository include:

1. Vulnerabilities or unsafe patterns in the reference policy examples under `examples/` or in `README.md`.
2. Supply-chain compromises, malicious redirects, or domain takeovers affecting any resource linked in `README.md`.
3. Vulnerabilities in the repository automation scripts (`scripts/`) or GitHub Actions workflows (`.github/workflows/`).

## Reporting a Vulnerability or Compromised Link

* For compromised external links or abandoned/hijacked domains in the catalog, open an issue or pull request removing the entry immediately.
* For vulnerabilities in repository scripts, workflows, or reference policy snippets, report privately via [GitHub Private Vulnerability Reporting](https://github.com/fabriziosalmi/awesome-compliance-as-code/security/advisories/new).

We review reports within 48 hours and remediate verified issues promptly.
